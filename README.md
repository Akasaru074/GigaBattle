# Giga battle (Qt Quick + Node.js)

Классическая игра "Морской бой", реализованная с использованием клиент-серверной архитектуры.

## 📋 Требования и функционал
- **Клиент:** Qt 6 (QML + C++)
- **Сервер:** Node.js + Express + ws
- **Сетевое взаимодействие:** WebSocket (JSON протокол)

## 🚀 Как запустить

### Сервер
1. Установите Node.js.
2. Перейдите в папку `server`:
   ```bash
   cd server
   npm install
   node server.js
